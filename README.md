# Tkinter Unit Converter

Простое десктопное приложение на Python для конвертации единиц измерения (километры в мили, килограммы в фунты, градусы Цельсия в Фаренгейты)[cite: 17].

## Установка

Убедитесь, что у вас установлен Python 3 и библиотека Tkinter[cite: 17].

## Запуск

Запустите главный файл проекта через терминал[cite: 9, 17]:
```bash
python main.py
